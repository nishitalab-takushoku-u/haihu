## 問題文_追加問題

#### 1.  次の条件を満たす MEX10.java を作成しなさい。整数 f を入力して、f の正負を調べて次のメッセージを表示する。f が 0 より大きいときは「f は正の数です。」f が 0 ならば「f は 0 です。」f が 0 よりも小さいときは「f は負の数です。」

【実行例 1】（斜体はユーザによる入力）

<pre>
% java MEX10
f = <i>5</i>
f は正の数です。
</pre>

【実行例 2】（斜体はユーザによる入力）

<pre>
% java MEX10
f = <i>-7</i>
f は負の数です。
</pre>
